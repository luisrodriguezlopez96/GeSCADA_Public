## Qué es GeSCADA

GeSCADA es una suite de ingeniería de escritorio para proyectos Siemens WinCC. Reúne herramientas para organizar datos exportados desde TIA Portal, revisar variables y cambios entre revisiones, reutilizar configuraciones y generar recursos que el ingeniero puede comprobar antes de incorporarlos al proyecto SCADA.

El repositorio público presenta las capacidades del producto; el código fuente completo no se distribuye aquí.

## Capacidades principales

- **Mapeado TIA y soporte Multi-PLC:** organiza variables, estructuras, instancias y fuentes procedentes de varios PLC.
- **Sincronización de cambios:** compara exportaciones sucesivas para identificar altas, modificaciones y elementos retirados, facilitando la revisión de actualizaciones.
- **Visor y auditoría de Tags:** permite consultar, filtrar y exportar datos del proyecto.
- **Biblioteca compartida de plantillas:** ayuda a reutilizar configuraciones de compresores, servicios y gráficas entre proyectos.
- **Generación de recursos:** prepara recursos gráficos y configuraciones para equipos y servicios de frío.
- **Alarmas e idiomas:** facilita la preparación de configuraciones de alarmas y recursos de texto multilingües.
- **Recursos auxiliares:** incluye herramientas de gestión de proyecto, organización de ventanas, scripts y exportaciones.

## Flujo de trabajo

1. Importar los datos exportados desde TIA Portal.
2. Revisar el mapeado y las estructuras del proyecto.
3. Comparar nuevas exportaciones cuando se dispone de una revisión actualizada.
4. Preparar los recursos necesarios para el proyecto WinCC.
5. Revisar y validar los resultados antes de utilizarlos en el entorno industrial.

## Estado y alcance

La versión 4.0.1 amplía el flujo de ingeniería con soporte Multi-PLC, sincronización incremental y una biblioteca compartida de plantillas. Algunas automatizaciones adicionales siguen en desarrollo y no deben considerarse capacidades listas para producción.

GeSCADA genera recursos para utilizar en WinCC; no sustituye la validación de ingeniería, las pruebas funcionales ni los procedimientos de puesta en servicio de la instalación.
