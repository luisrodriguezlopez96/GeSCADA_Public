GeSCADA 4.0.1 · Windows

Del export de TIA Portal a un proyecto WinCC más consistente y fácil de mantener.

GeSCADA ayuda a los ingenieros de automatización a preparar, revisar y actualizar proyectos SCADA. Centraliza el mapeado de variables, facilita la revisión de cambios entre revisiones y genera recursos de ingeniería para comprobarlos antes de incorporarlos a WinCC.

Proyecto independiente de ingeniería industrial, centrado en tareas repetitivas del ciclo TIA Portal → WinCC.

Origen

Menos tareas repetitivas. Más tiempo para revisar el proyecto.

Parte del trabajo de ingeniería SCADA exige repetir procesos entre exportaciones, revisión de variables, configuración de equipos y preparación de recursos para WinCC.

GeSCADA reúne en un mismo flujo tareas como organizar los datos de TIA Portal, revisar variables y cambios, preparar configuraciones de equipos y generar recursos para el proyecto WinCC.

Empezó como hojas de cálculo

La necesidad de organizar tareas repetitivas fue el punto de partida para reunir herramientas de ingeniería en una aplicación de escritorio.

Se convirtió en una aplicación

Las herramientas permiten revisar los datos del proyecto y preparar distintos recursos desde una interfaz común.

Hoy automatiza el flujo completo

Flujo

Interpretar, revisar y generar.

GeSCADA reúne las tareas clave del ciclo de ingeniería y ayuda a revisar los resultados sin sustituir el criterio del ingeniero ni la validación final en WinCC.

1

Interpretar

Importa y organiza los datos exportados desde TIA Portal para consultar variables, estructuras, instancias y fuentes PLC.

2

Validar

Facilita revisar diferencias entre revisiones y localizar elementos que necesitan atención antes de continuar.

3

Generar

Prepara mapeados, recursos gráficos, configuraciones y exportaciones que el equipo de ingeniería puede revisar antes de utilizarlos en el proyecto.

💡 La clave: GeSCADA facilita revisar el estado del proyecto antes de utilizar los recursos generados. La aceptación final corresponde al equipo de ingeniería.
Módulos

Herramientas para el ciclo de ingeniería SCADA.

La línea 4.x amplía el flujo inicial con trabajo multi-PLC, sincronización de cambios y una biblioteca de plantillas compartida.

Mapeado multi-PLC

Organiza datos procedentes de varios PLC, manteniendo diferenciadas las fuentes y facilitando la revisión conjunta del proyecto.

Sincronización Delta

Compara nuevas exportaciones con el estado previo para identificar altas, modificaciones y elementos retirados, con un alcance de revisión más claro.

Biblioteca de plantillas compartida

Permite reutilizar y mantener plantillas de compresores, servicios y gráficas entre proyectos, con versiones que facilitan controlar su evolución.

🔍
Módulo 1

Mapeador WinCC

Organiza los datos exportados desde TIA Portal y facilita la consulta de variables, estructuras e instancias para preparar el proyecto WinCC.

  • Revisa y organiza los datos antes de generar recursos.
  • Exporta resultados para las siguientes etapas de ingeniería.
📋
Módulo 2

Data Hub — Visor de Tags

Consulta variables, estructuras, instancias y datos asociados desde una vista centralizada, con herramientas para filtrar y revisar la información del proyecto.

  • Consulta y filtra la información que necesita revisar el ingeniero.
  • Exporta los datos revisados a Excel o CSV.
🔧
Módulo 3

Compresores 2.0

Generador especializado para compresores — los equipos con mayor densidad de variables. Valida la existencia de cada variable en tiempo real y genera en bloque la preconfiguración gráfica, las estructuras de variables para WinCC y sus variables base.

❄️
Módulo 4

Generador de Servicios de Frío

Detecta automáticamente los espacios refrigerados del proyecto — cámaras, salas, túneles — y genera por cada uno la preconfiguración gráfica con autoajuste de rango de temperatura y las estructuras de variables para WinCC.

📈
Módulo 5

Generador de Gráficos

Detecta automáticamente bombas, separadores, condensadores y otros equipos auxiliares en el mapeado. Genera en bloque la preconfiguración gráfica lista para WinCC — sin tocar un archivo a mano.

🎨 Recursos reutilizables — Las herramientas para compresores, servicios y gráficas permiten aplicar configuraciones comunes a los equipos del proyecto y generar recursos de forma consistente.
Módulos 3–5: Gráficas automáticas generadas por tipo de equipo sin intervención manual.
Configuración: Prefijos, paleta de gráficas, logging y parámetros globales del proyecto.
🚨
Módulo 6

Gestor de Alarmas

Prepara la configuración de alarmas y facilita comparar revisiones para identificar alarmas nuevas, modificadas o retiradas.

Permite revisar los cambios antes de actualizar la configuración del proyecto.

⚙️
Módulo 7

Scripts de Sistema

Prepara scripts auxiliares, tareas programadas y rutinas de apoyo para la operación y el mantenimiento del entorno Windows.

Resultados

Menos trabajo manual. Más consistencia entre TIA Portal y WinCC.

El objetivo es reducir la manipulación repetitiva y facilitar la revisión de los recursos generados.

Menos trabajo manual

Reduce tareas repetitivas entre exportación, revisión y preparación de resultados para WinCC. El ingeniero se centra en lo que aporta valor.

Más consistencia

El mapeado actúa como base común que refuerza la coherencia entre origen, validación y salida. Una sola fuente de verdad para todo el proyecto.

Validación antes de generar

Ayuda a detectar errores antes de que lleguen a la fase final de configuración o importación, donde el coste de corrección es mayor.

Casos de uso

Ejemplos de trabajo con GeSCADA.

Desde la preparación inicial hasta la revisión de cambios y la reutilización de configuraciones.

Proyecto nuevo

  1. Exportar desde TIA Portal.
  2. Cargar y mapear el proyecto.
  3. Validar y revisar integridad.
  4. Preparar resultados para WinCC.

Actualización de proyecto

  1. Cargar una nueva exportación.
  2. Detectar cambios relevantes.
  3. Regenerar solo lo necesario.
  4. Aplicar cambios con más control.

Auditoría de integridad

  1. Revisar score y excepciones.
  2. Detectar huérfanos y duplicados.
  3. Corregir sobre la base de origen.
  4. Recargar con trazabilidad.
